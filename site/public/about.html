About Crewship

What Crewship is

Crewship is a repeatable cloud-server setup for running coding agents in parallel.

It brings Firstmate, omp, Herdr, and an Ansible playbook together on your server.

Who it serves

Crewship serves developers who want many coding agents on their own server, with one supervisor and shared tools.

How the parts work together

  • Ansible provisions the host.
  • Firstmate supervises coding agents and hands work to second mates, who lead workers.
  • omp runs the agents. Each worker uses its own isolated copy of the repository.
  • Herdr shows workspaces, agents, state, and load in its sidebar.

What is included

The installer offers a feature checklist and installs omp agents and Firstmate.

  • Supervision and workspaces: Firstmate coordinates agents, and the Herdr sidebar shows their work.
  • Guards (optional): block pkill, gate quality, and clean up stray containers and development servers.
  • Credentials: use one super.env file. An external private Worker can supply it to new hosts.
  • Web gateway (optional): one password opens agent pages and previews.
  • Message board (optional): agents on one host communicate through in-memory topics.
  • Browser ladder (optional): start with a light browser; use full Chrome or noVNC when needed.
  • Chat clients (optional): use Discord, Slack, and iMessage from the terminal.
  • Mac control (optional): agents control apps on your Mac over SSH.

See the README feature list for the linked guides and supporting tools.

What you need

  • A fresh Ubuntu 24.04 or 26.04 server with systemd.
  • At least 4 vCPUs and 16 GB of RAM.
  • SSH access with a non-root account that has sudo.
  • Sign-ins for GitHub and the model providers you use.

How to start

Follow the README quick start for the current install command.

Use the SETUP guide for the setup flow and manual sign-in steps.

The setup command checks or resumes setup. To update, run the install command again.

Control, safety, and limits

The agents run on your server and use model providers and GitHub. Web access, chat, and Mac control are optional.

Review and check agent changes before use. Keep credentials private and enable only the remote access you need.

Read the security guide and architecture guide before you configure access.

Short factual answers

Where does it run?

On your server. You reach Firstmate from a phone or laptop through a terminal over SSH or optional iMessage.

Which server systems are supported?

The README lists Ubuntu 24.04 and 26.04 with systemd.

Do I need every optional tool?

No. The installer offers a feature checklist. The gateway, board, browser ladder, chat clients, and Mac control are optional.

Do I need provider accounts?

The workers use model providers and GitHub. Follow the SETUP guide for the required sign-ins.
