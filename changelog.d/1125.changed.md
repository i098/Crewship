The browser ladder's last tier is now `voxl`, replacing the TigerVNC and noVNC tier: `fleet-browser up voxl` streams the headed browser with [voxl](https://github.com/tembo/voxl) on the same port 6909, behind a password, with the same browser profile, so the shared logins stay. The `fleet_browsers` and `fleet_guards` profiles build the latest voxl release crate, verified against its published SHA-256, and install the Rust toolchain for it. Apply removes the old `fleet-browser-vnc.service` unit ([#1125](https://github.com/i098/Crewship/issues/1125)).
