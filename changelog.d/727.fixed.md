Crewship installs managed `gh` and `gh-axi` wrappers that validate actual issue-write arguments before either CLI starts.
Missing targets and task-target mismatches stop before preliminary network calls; body text does not supply a repository.
GraphQL issue mutations and unresolved targets are blocked even with approval, and dependent `gh-axi` operations stop before partial writes.
Native and npm upgrades preserve the wrappers. The issue helper uses the explicit Crewship repository, and the board uses Project REST endpoints.
Issue creation now checks parent targets, and `gh-axi` repository flags reject URLs and trailing slashes.
