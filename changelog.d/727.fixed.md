Crewship now installs a managed `gh` wrapper that validates actual issue-write arguments before executing the verified GitHub CLI.
The wrapper also covers `gh-axi` calls that delegate to `gh`, preserves approved upstream writes, and ignores unrelated repository mentions in bodies.
Repository contracts apply when `CREWSHIP_GITHUB_REPO` is set; missing-target blocking is always active.
The omp extension retains its process-kill checks without GitHub command-text scanning.
Read-only issue flags pass through unchanged; observed `gh-axi` sub-issue GraphQL writes still require explicit repository approval.
