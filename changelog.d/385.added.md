The `instagram-dm` skill now uses `instagrapi` (saved session, email-code login). With `crewship_instagram_dm_operator` set, a `firstmate` host keeps a realtime listener and a backstop poll timer that file each new DM from the operator with the Firstmate inbox (read receipt included), and installs `fm-insta-reply` to answer by text, reaction or typing indicator. No media is downloaded.
