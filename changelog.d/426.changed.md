**Breaking:** the `shared_postgres` profile no longer runs one host-wide Postgres container. Each project gets one dev database container of the engine its own compose file names (Postgres, MySQL, MariaDB or Redis), shared by all of its worktrees, with its own port, password and data volume, and the seeder writes `DATABASE_URL` or `REDIS_URL` into each worktree's `.env.local`. The `crewship-shared-postgres` container and its volume stay untouched; [Project databases](docs/shared-postgres.md#migrate-from-the-host-wide-postgres) explains how to move the data
