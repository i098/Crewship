The worker image is smaller: a `builder` stage provisions it and deletes the files no worker process reads (apt indexes, node C headers, source maps and TypeScript declarations in the npm tool prefixes, omp's unused `onnxruntime-web` and extra `onnxruntime-node`, the AVX2 copy of omp's native addon, and Mesa's GPU driver and LLVM), strips the symbol tables of the rustup toolchain and the npm native addons, and the `worker` stage copies the result into one layer; `.dockerignore` also keeps the Dockerfile, the changelog, the contributor and setup guides and `install.sh` out of the build context.
