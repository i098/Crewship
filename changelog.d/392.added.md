The new public skill `openmontage` makes videos on demand with OpenMontage: install pointer, key names, `render.py` for Remotion props and three.js scenes (a rotating moon sample included), and `screencast.mjs`, which records a live site through Chrome DevTools into the cache dir that is pruned after 1 day; `render.py` can send a poster frame with `fm-imessage --image` (#392).
