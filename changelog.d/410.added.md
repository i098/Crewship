The new `slack-relay` skill relays important Slack messages to iMessage: it reads the slk TUI cache read-only, keeps DMs, mentions, thread replies, decisions, deadlines, asks and incidents with one `omp -p` call, sends at most one `fm-imessage` text per minute, dedupes by message ts and logs every kept or dropped message. It ships an opt-in `systemd --user` unit and never writes to Slack (#410).
