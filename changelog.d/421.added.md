`forgejo-github-push enable <owner>/<repo> <GitHub URL>` makes a Forgejo repository push every branch that a push created or updated, except its default branch, to GitHub. It never pushes the default branch or tags and never deletes a GitHub branch. A push that fails three times stays as a failed `forgejo-github-push-*` user unit. New Forgejo push mirrors are off, because a push mirror deletes every GitHub branch that it does not push.
