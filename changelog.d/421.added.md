`forgejo-github-push enable <owner>/<repo> <GitHub URL>` makes a Forgejo repository push every branch that a push created or updated, except `main`, `master` and its default branch, to GitHub. Each push leases on the commit the hook last pushed for that branch, so a rebased branch replaces it, but a commit made only on GitHub (Update branch, a suggestion, a web edit) is never overwritten: the push fails and each later push of the branch warns until the branch merges it. It never pushes `main`, `master`, the default branch or tags and never deletes a GitHub branch. A push that fails three times for another reason stays as a failed `forgejo-github-push-*` user unit. Forgejo mirrors are off, also in the API, because a push mirror deletes every GitHub branch that it does not push.
