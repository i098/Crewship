`forgejo-github-push enable <owner>/<repo> <GitHub URL>` makes a Forgejo repository push its created or updated feature branches to GitHub after each push. It never pushes main or tags and never deletes a GitHub branch. A push that fails three times stays as a failed `forgejo-github-push-*` user unit. Forgejo mirrors are off, also in the API, because a push mirror deletes every GitHub branch that it does not push.
