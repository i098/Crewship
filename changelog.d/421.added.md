`forgejo-github-push enable <owner>/<repo> <GitHub URL>` makes a Forgejo repository push every branch that a push created or updated, except `main`, `master` and its default branch, to GitHub without force. It never pushes `main`, `master`, the default branch or tags and never deletes a GitHub branch or a GitHub commit. When GitHub has commits that a branch lacks, the push fetches them into the Forgejo repository as `refs/github-ahead/<branch>`, the push unit fails, and each later push of the branch warns until the branch has them. A push that fails three times for another reason stays as a failed `forgejo-github-push-*` user unit. Forgejo mirrors are off, also in the API, because a push mirror deletes every GitHub branch that it does not push.
