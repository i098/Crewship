The `forgejo` profile switch turns on the Forgejo recipe; [Self-hosted Forgejo](docs/forgejo.md) describes it. `forgejo-github-push enable <owner>/<repo> <GitHub URL>` makes a Forgejo repository push its created or updated feature branches to GitHub after each push. It never pushes main or tags and never deletes a GitHub branch. New Forgejo push mirrors are off, because a push mirror deletes every GitHub branch that it does not push.
