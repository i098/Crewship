With services enabled, `launch` now opens `crewship schedules` in a `schedules` tab in the Herdr `machine` workspace.
It creates missing workspaces, preserves custom tabs, and resumes the viewer in a restored idle shell.
It leaves running commands and split tabs unchanged.
Set `crewship.herdr.schedules_tab: false` to skip this setup.
The existing installer supplies the CLI link in `~/.local/bin`.
