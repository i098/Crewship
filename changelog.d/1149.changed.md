The browser ladder's voxl tier is now a permanent user service on port 6913, enabled at boot and started once the shared cookie jar exists. `fleet-browser-gc.timer` no longer stops it. A guard logs and stops voxl if the jar count falls more than 5% between two checks. Apply publishes `https://<tailnet host>:6913/` with `tailscale serve` when Tailscale has HTTPS certificates, and the old noVNC packages stay installed and inactive as the rollback ([#1149](https://github.com/i098/Crewship/issues/1149)).
