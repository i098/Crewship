Install the latest `compact-adviser` with the `agents` profile and load it in omp in automatic mode, so a session compacts at a checkpoint TypeSafe Jev judges finished. A compaction it starts tries snapcompact three times, then remote, then soft. The extension reads `TYPESAFE_API_KEY` from the environment or `~/super.env`, skips sessions that match `~/.omp/agent/compact-adviser-deny.json`, and stays off where `COMPACT_ADVISER_DISABLE=1` is set ([#1108](https://github.com/i098/Crewship/issues/1108)).
