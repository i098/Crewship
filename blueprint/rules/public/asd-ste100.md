---

Write every human-facing text in ASD-STE100 Simplified Technical English: chat replies, status lines, PR and issue text, commit messages, docs, and reports. Use approved words with one meaning each, and keep one meaning per word in a text. Write one topic per sentence: 20 words maximum for an instruction and 25 for a description. Use the active voice and simple verb tenses, and start each instruction with a verb. Do not drop articles. Code, identifiers, commands, and quoted text stay as they are.
