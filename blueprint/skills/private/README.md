# Private skills

Skills that stay on this host. Git ignores everything in this folder except this file, so nothing here is committed or shared. Put each skill in `skills/private/<name>/SKILL.md`, or set `skills.private_source` to fill this folder from a private source on every apply. The `agents` profile installs them like [public skills](../public/README.md), and a private skill wins over a public skill with the same name. See [Skills](../../docs/omp.md#skills).
