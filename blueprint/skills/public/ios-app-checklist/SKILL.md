# iOS app checklist

Check each item before you submit the app. This checklist comes from one reel; verify current Apple requirements before release.

- Add an account deletion button.
- If the app uses Google login, add a second login option.
- Add a demo login for the reviewer.
- Remove placeholder text.
- Test the app on a real iPhone and check for crashes.
- Add links to a privacy policy and support page.
- Make privacy labels and age ratings accurate.
- Add a privacy manifest.
- State a reason for every permission request.
- Build with the latest Xcode.
- Ask before tracking or sending data to an AI service.
- Use in-app purchases for upgrades.
- Show the price and terms on the paywall.
- Add a restore button for subscribers.
- Add report and block controls for user content.
- Do not use brand names without permission or hide app features.
