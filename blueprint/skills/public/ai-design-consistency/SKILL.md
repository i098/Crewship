# AI design consistency

Set a clear point of view for users. Stripe uses “Optimism” to guide color, copy, and design.

Encode design standards, the design system, templates, and flows in CLI tooling. A loose design tool gave three users three different results.

Generate and test many ideas. Edit and inspect details as a user. Ask adversarial agents to critique the design.

## Apply

- [ ] Set the point of view that guides the design.
- [ ] Encode standards, system, templates, and flows in CLI tooling.
- [ ] Generate and test many ideas.
- [ ] Edit and inspect details as a user.
- [ ] Ask adversarial agents to critique the design.
