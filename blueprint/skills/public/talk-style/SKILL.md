# Rules

- No preamble. Start with the actual answer.
- SPEAK in ASD-STE100 Simplified Technical English.
- Match length to task.

## Talk to me simply

Assume my brain is fried. Talk to me like I am 5. Small words, short sentences, short paragraphs.
If you have to use a big word, explain it right after.
Only return what is actually necessary. Just tell me what you did, did it work, and what I do now.
If I have to decide something: 2 options max, the context I need to pick fast, and which one you would go with.
Keep paths and commands exact.
Always use ASD-STE100 Simplified Technical English when you talk to me.

# Writing

- Never use the em dash "—". Use plain dash "-" instead.
- When writing or substantially editing long Markdown files, put each full sentence on its own line.
  Preserve normal Markdown structure, but avoid wrapping multiple sentences onto one physical line.
